# クイズパネル（回答者）

クイズパネルの回答者用ページです。スマホで開いて、参加コード（6桁）と名前を入れて参加します。
ホスト画面は別のリポジトリ **panel-host** にあります。

- 回答者画面: `https://<ユーザー名>.github.io/Answer/`
- ホスト画面に表示される QR コードを読み取ると、参加コードが入った状態で開きます（`?code=123456`）。

## できること

- 記述（文字）・選択式・手書き（フリップ）で回答。締め切りまでは何度でも変更できます。
- 回答がホストに届くと「✓ ホストに届きました」と表示。届いていなければ自動で送り直します。
- 正解発表で ○ / × と正解、いまの得点と順位を表示。最終結果では自分の順位を表示します。
- 再読み込みやスリープからの復帰でも、続きから参加できます（6時間操作がないと自動では再接続しません）。
- ホストがアンケートモードにしているときは、得点・正解・順位は表示せず、回答を送るだけになります。

## 公開のしかた（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save

## ファイル構成

```
index.html        回答者画面
css/player.css
js/config.js      設定 ※ ホスト側と同じ内容にする
js/net.js         複数サーバーへの同時接続（ホスト側と共通）
js/common.js      共通の道具（ホスト側と共通）
js/player.js      回答者画面の本体
vendor/           mqtt.js の予備（jsDelivr から読み込めないときに使う）
```

通信のしくみ・つながらないときの対処は、panel-host の README を見てください。

**公開の MQTT サーバーを中継に使うため、個人情報や秘密の内容は入力しないでください。**
